# Logos

Inks: letters `#14130F` (ink) on paper, `#F4F1E9` (paper) on carbon; nuqtas `#E0461F` on paper, `#FF5A33` on carbon. SVGs are fixed-colour (no `currentColor`); for a recolourable logo use the `Logo` component.

- `athr-wordmark.svg` — primary logo: ink + vermilion nuqtas, for paper grounds.
- `athr-wordmark-mono.svg` — one ink, for one-colour print and engraving.
- `athr-wordmark-reverse.svg` / `athr-wordmark-reverse-mono.svg` — for carbon grounds.
- `athr-arabic.svg`, `athr-arabic-mono.svg`, `athr-arabic-reverse.svg` — the أثر wordmark; the brand nuqtas replace ث's dots.
- `athr-bilingual.svg`, `athr-bilingual-reverse.svg` — secondary lockup for proposals, signage, footers.
- `athr-symbol.svg` (vermilion), `-accent` (vermilion top, ink base), `-mono`, `-reverse` — favicon, avatar, small spaces.
- `app-icon-dark.svg` (default), `app-icon-light.svg` — 1024px, square; the OS applies the corner mask.
- `favicon.svg` — 32px, carbon with rounded corners. `social-avatar.svg` — 800px, circle-safe.
