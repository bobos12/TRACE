# Nuqta

The signature rhombus — the dot that makes ت into ث, used as ATHR's recurring mark.

- `size` (px), `tone`: `mark` (vermilion, default) · `accent` (`nuqta`) · `ink` · `muted`. `stamp` plays the press-in animation once.
- Where it appears: the active nav/tab indicator, bullets, the "you are here" marker, timeline events, and as the full stop of a display line (`<span class="at-stop">`).
- One vermilion nuqta per view region. If everything is marked, nothing is. Never as decoration scattered on a background.
