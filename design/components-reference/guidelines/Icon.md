# Icon

Line icons on a 24px grid: 1.5px stroke, square caps, mitred joins, status icons built on the rhombus.

- `name` (see the preview), `size` (default 20), `label` for a meaningful icon (otherwise hidden from screen readers), `flip` mirrors directional icons in RTL.
- Icons take `currentColor`. Pair with text wherever the meaning isn't obvious. The `nuqta` icon is solid — use it as a bullet, not as a button glyph.
