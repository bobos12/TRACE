# Design reference

Approved designs. Open any `.html` in a browser (the `_shared/` folder must stay next to them). Each page has a Light / Dark switch.

- `pages/home-en.html`, `pages/home-ar.html` — home page typographic system, grid, components (the new home spec in `docs/03-home-page.md` adds more visuals on top of this)
- `pages/case-study.html` — project detail layout
- `pages/saas-dashboard.html`, `pages/mobile-app.html` — the product UI shown in `public/images/ui/`
- `pages/business-proposal.html`, `pages/social-media.html`, `pages/brand-applications.html` — identity applied
- `components-gallery.html` + `components/` — all 23 UI components, live
- `renders/*.png` — every page and the visual-directions board, light and dark @2x
