# Setup checklist

Do these in order. Every file named here is in this kit.

## 0. Before anything

- [ ] Pick one handle and use it everywhere. Suggestions, in order:
      `@trace.studio` · `@tracestudio` · `@trace.software` · `@tracebuilds`.
      Check availability on all platforms first (namechk.com).
- [ ] Use the company email (not a personal one) to register every account.
- [ ] Turn on two-factor authentication on every account.
- [ ] Add a second admin (a co-founder or a trusted teammate) to each page.
