# Website direction

See the **Website** page. The site is an editorial document, not a template.

- **Hero:** one sentence set huge in `display-xl`, the second half in `ink-muted`, ending in the nuqta; the Arabic line set beside it, not beneath it. No 3D object, no illustration, no code screenshot. A single hairline closes the hero with a nuqta placed on it — the trace.
- **Structure:** numbered sections (`01 ◆ HOW WE WORK`) on a 12-column grid with the heading offset to column 4 — asymmetry instead of centred stacks.
- **How we work:** three columns under an ink rule: Understand → Build around it → Leave a mark.
- **Work:** large case panels with the cut corner, each carrying the client's constellation and three hard numbers.
- **Services:** a ruled 4×2 index, not icon cards.
- **Arabic band:** a full carbon section in Arabic — both languages present on the English home page, and vice versa.
- **CTA:** "Tell us how your business works." One button.
- **Motion:** headline lines rise 8px and fade once; the hero hairline traces in; nothing else moves until the user does.
- **Arabic site:** mirrored layout (`dir="rtl"`), Arabic wordmark in the nav, `ar-*` styles, same components.
